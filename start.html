/you

Your license key is on the Whop page you came from. Everything else is here, and it takes three things.

1 · Connect

The setup connector lives at this site/api/setup. Add it where your AI lives. One of these.

claude.ai, and the Claude app

Settings, Connectors, Add custom connector. Name it you, no sign-in, and the address:

https://this-site/api/setup

Claude Code

In your terminal:

claude mcp add --transport http you https://this-site/api/setup

Codex

In ~/.codex/config.toml:

[mcp_servers.you]
url = "https://this-site/api/setup"

Any other AI

If it can add an MCP server, it can do this: an HTTP server named you at that address. No token, no sign-in. The license key is the door.

2 · Say it

An AI that turns a connector's prompts into commands, Claude Code among them, now has one. Type /you and pick it. Everywhere else, say this:

Set up my Wire.

It asks for your key, then gives you one line at a time. Say done after each. It never asks for a password, token or key, and you never paste one into the chat.
